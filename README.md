# baccaratmaker

모바일 브라우저에서 바로 실행할 수 있는 바카라 마틴 진행 페이지입니다.

## 기능

- 시작금액, 1마틴 금액, 마틴횟수 입력
- 1페이지 금액 세팅 / 2페이지 게임 진행 구조
- 카드 셔플 애니메이션 뒤 `플레이어` 또는 `뱅커` 랜덤 생성
- `승리`, `패배` 버튼으로 판정 처리
- 마틴 단계별 배팅금액 자동 계산
  - 예: 1, 3, 7, 15 ...
- 진행 기록 누적 표시
- 진행 종료 시 판 횟수, 시작금액, 총 수익, 총 금액 요약 표시
